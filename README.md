
# Carga de Dimensiones - Data Warehouse

## 1. Descripción del proyecto

Este proyecto consiste en la creación y carga de las dimensiones de un almacén de datos (Data Warehouse), utilizando Microsoft SQL Server.

## 2. Objetivo

Implementar un modelo dimensional que permita organizar y consultar información de ventas de manera eficiente.

## 3. Base de datos

Nombre: DW_ITLA

Motor de base de datos: Microsoft SQL Server.

Modelo: Esquema estrella.

## 4. Dimensiones creadas

- DimFecha: almacena información relacionada con fechas.
- DimCliente: almacena información de los clientes.
- DimProducto: almacena información de los productos.
- DimSucursal: almacena información de las sucursales.
- DimVendedor: almacena información de los vendedores.

## 5. Proceso realizado

1. Creación de la base de datos.
2. Creación de las tablas dimensionales.
3. Inserción de datos de ejemplo.
4. Carga de fechas.
5. Verificación de los registros mediante consultas SQL.

## 6. Herramientas utilizadas

- GitHub.
- Microsoft SQL Server.
- SQL Server Management Studio.
- SQL (T-SQL).

## 7. Estructura del proyecto

- sql/: contiene los scripts SQL.
